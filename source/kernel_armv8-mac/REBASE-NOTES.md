## Reproducing

```sh
tools/rebase-asahi-onto-slackware.sh    # -> linux-6.18.33-mac.tar.gz
```

Commit SHAs differ on every run (a commit hash includes its timestamp), so
none is recorded here. The tarball is written reproducibly (names sorted,
every mtime the Asahi tag's commit time, owner and group 0, gzip without a
timestamp), so a rerun reproduces its sha256 as well as its content, and
this file byte for byte.

The script refuses to emit a tarball if the Apple driver directories or
the Mac mini device tree are absent from the result, so a rebase that
silently dropped `drm/apple` or `drm/asahi` cannot be packaged as if it
had not. It also stops rather than resolving an unrecorded conflict.
